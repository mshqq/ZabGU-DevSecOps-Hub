# Контракты сканера

Как правило детектирования (`app/scanner/rules/`) общается с кодом скана.

## Что получает правило

Правило получает объект `ScanContext` с: путём до временного клона репозитория, коммитом, на котором
сканируем, и списком файлов. Больше ничего - правило не лезет в сеть, не трогает БД напрямую.

## Что возвращает правило

Метод `Rule.scan(ctx)` возвращает список находок. Каждая находка - это поля модели `Finding` (см.
README), кроме `id`, `scan_id`, `status` - их проставляет код скана при сохранении.

Обязательно: `masked_value` - секрет только в маскированном виде (`AKIA****WXYZ`), никогда открытым
текстом. Маскирует само правило.

## Пример находки

```json
{
  "rule_id": "AWS_ACCESS_KEY",
  "severity": "P0",
  "confidence": "high",
  "source": "regex",
  "file_path": "config/settings.py",
  "line_no": 42,
  "masked_value": "AKIA****WXYZ"
}
```
